학교 등록 방법

궁금한 게 있나요?

처음 쓰기 전에 많이 궁금해하는 것들이에요.

무료인가요?{% include icon.html name="plus" %}

네, 무료예요. 봇 안의 돈과 주식은 게임용 데이터라서 현금으로 바꿀 수 없어요.

어떻게 초대하나요?{% include icon.html name="plus" %}

위의 ‘서버에 초대하기’를 눌러 서버를 고르고 요청한 권한을 허용하면 돼요. 서버를 관리할 수 있는 권한이 있어야 초대할 수 있어요.

왜 이런 권한이 필요한가요?{% include icon.html name="plus" %}

메시지 보내기와 음성 채널 연결은 명령어 응답과 음악 재생에, 메시지 관리와 채널 관리는 메시지 정리·슬로우모드·채널 잠금에 써요. 멤버 추방·차단·타임아웃은 서버 운영 명령에, 별명 변경은 서버에서 봇 이름을 OMNI로 맞추는 데 써요.

관리자(Administrator) 권한은 요청하지 않아요.

명령어가 보이지 않아요{% include icon.html name="plus" %}

디스코드를 새로고침(Ctrl+R)해 보세요. 서버 운영 명령은 서버 관리 권한이 있는 역할에게만 보여요. 서버 설정의 연동에서 OMNI를 열면 명령어별 사용 권한을 바꿀 수 있어요.

어떤 정보를 저장하나요?{% include icon.html name="plus" %}

게임 기능에는 Discord 사용자 ID와 잔액, 출석 기록처럼 기능에 필요한 정보만 저장해요. 마지막으로 쓴 뒤 12개월이 지나면 삭제돼요. 항목별 보유 기간은 개인정보 처리방침에서 확인할 수 있어요.
